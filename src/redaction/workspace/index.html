Running locally — verify it yourself

Every step — parsing, detection, redaction, download — happens in this browser tab. This workspace processes documents locally and shares its saved settings only with the surrounding Loonie Ledger app. It does not send them to an external service.

  1. Open your browser's developer tools and switch to the Network tab.
  2. Turn off Wi-Fi, or use the devtools Offline mode.
  3. Configure values, drop a document, review, and download the redacted copy.
  4. The redaction workspace loads its bundled PDF engine from this local server as needed. It makes no external document requests. Its Content-Security-Policy blocks connections to other origins; Loonie Ledger’s separate optional AI tools can still send the text you choose to share.

What is stored, and where

Only your value vault (the “My information” list) persists — encrypted with AES-GCM using a non-extractable key held by this browser profile, in IndexedDB. The surrounding app can use this key; encryption does not isolate the profile from app scripts. Documents are processed in memory and are gone when the tab closes.

Threat model, plainly

This protects you from sending identifiers to cloud services. It does not protect against malware on your own machine, anyone with access to your browser profile, or re-identification from context that remains in the document. It is a privacy-hygiene aid, not a compliance tool or legal review.
